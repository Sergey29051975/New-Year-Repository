# Contributing

Thank you for your interest in this collection of New Year English activities.

## Project Focus

This repository is focused on practical English learning materials connected with New Year topics.

## Useful Contributions

- vocabulary activities
- speaking questions
- writing tasks
- classroom games
- teacher notes
- printable worksheets

## Content Style

Please keep materials:

- clear
- classroom-friendly
- easy to adapt
- suitable for A2 to B2 learners
- organized by folder

## Suggested Structure

```text
01-vocabulary/
02-speaking-prompts/
03-writing-tasks/
04-discussion-cards/
05-games/
06-worksheets/
```
