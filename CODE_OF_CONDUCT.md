# Code of Conduct

## Our Standards

This project supports respectful and constructive work on English learning materials.

Positive behavior includes:

- using polite and professional language
- giving practical feedback
- respecting teachers and learners
- keeping discussions focused on educational value

Unacceptable behavior includes:

- personal attacks
- harassment
- offensive language
- publishing private information
- disruptive comments

## Scope

This code applies to issues, pull requests, discussions, and documentation connected with this repository.

## Enforcement

The maintainer may remove content or close discussions that do not support the purpose of the project.
